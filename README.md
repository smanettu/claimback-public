# ClaimBack

[Privacy Notice](https://smanettu.github.io/claimback-public/privacy/)

[Support and data requests](https://smanettu.github.io/claimback-public/support/)

Public information for the ClaimBack mobile app, provided by Smanettu.

## Structure and publishing

This repository follows `smanettu/unvestly-public`: Markdown pages in `privacy/`
and `support/`, with versioned public configuration in `config/v1.json`.
GitHub Pages publishes the root of the `main` branch. Push changes to `main`
to publish updates; no separate website build or hosting account is needed.

The initial configuration contains only a schema version. ClaimBack does not
currently fetch it; it is reserved for future explicitly implemented settings.
Do not put credentials, receipt data, personal messages or private app code here.
